polish-electricity-tariffs

Statyczne dane taryf energii elektrycznej dla polskich operatorów, serwowane przez GitHub Pages — bez serwera. Dowolna aplikacja (np. integracja Home Assistant) może pobrać ceny zamiast zmuszać użytkownika do ręcznego wpisywania stawek.

Dane

  • data/index.json — lista operatorów
  • data/tauron.json — TAURON (G11, G12)

Stawki netto z taryf zatwierdzonych przez Prezesa URE. Szczegóły formatu w README repozytorium.
